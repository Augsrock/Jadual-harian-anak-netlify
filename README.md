# 📅 Jadual Harian Anak

**Jadual Harian Anak** ialah aplikasi web yang membantu ibu bapa membentuk **sahsiah diri, disiplin dan keperibadian cemerlang** anak-anak melalui rutin harian yang konsisten.

Aplikasi ini direka khas untuk kanak-kanak berumur **4 hingga 12 tahun** dengan jadual harian yang mudah difahami, sistem ganjaran, dan pemantauan perkembangan.

---

## ✨ Objektif

Membantu ibu bapa untuk:

* 🌱 Membina disiplin harian
* 🤝 Meningkatkan kemahiran sosial
* ❤️ Membentuk akhlak dan adab yang baik
* 📚 Memupuk minat membaca dan belajar
* 🕌 Menggalakkan amalan agama dan nilai murni
* 💪 Mewujudkan rutin yang sihat

Data yang disimpan termasuk:

* Maklumat anak
* Jadual harian
* No telefon
* Carta bintang

## 🌐 Deployment

Aplikasi dihoskan menggunakan **Netlify**.

### Auto Deployment

Setiap kali perubahan di-*push* ke **main branch**, Netlify akan:

1. Mengesan perubahan daripada GitHub.
2. Membina (build) aplikasi secara automatik.
3. Deploy versi terkini tanpa sebarang konfigurasi manual.

---

## 🔄 Deployment Flow

```text
Developer
     │
     ▼
 GitHub (main)
     │
     ▼
 Netlify Auto Deploy
     │
     ▼
 Live Website
```
